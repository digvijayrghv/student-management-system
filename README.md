# Student Management System

A Python application to add, view, search, update and delete student records.

## Features
- Add a new student
- View all students
- Search by name or roll number
- Update and delete records

## Tech Used
- Python 3
- (SQLite / CSV file, whichever you use)

## How to Run
1. Install Python 3.
2. Clone this repository:
   git clone https://github.com/YOUR-USERNAME/student-management-system.git
3. Go to the folder and run:
   python main.py
