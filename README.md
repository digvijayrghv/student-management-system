# Student Management System

A Python application to add, view, search, update and delete student records.

## Features
- Add a new student
- View all students
- Search by name or roll number
- Update and delete records

## Tech Used
- Python 3
- (SQLite / CSV file, whichever you use)

## Future Improvements
- Add a GUI with Tkinter
- Move storage to a SQL database
